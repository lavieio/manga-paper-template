## 你现在看不到这篇文章

如果你在正常的站点上读到这些字，说明草稿过滤失效了——那是个 bug，请告诉我。

因为这篇 frontmatter 里写着：

```yaml
draft: true
```

## 草稿的规则

| 行为 | 草稿 | 正式文章 |
| --- | --- | --- |
| 生成页面 | ❌ 完全没有产物 | ✅ |
| 列表 / 归档 / 标签 / 分类 | ❌ | ✅ |
| RSS / sitemap / 搜索索引 | ❌ | ✅ |
| 注入 `date` | ❌ 还没到发布的时候 | ✅ |

构建时所有列表都走同一个入口 `getPublishedPosts()`，草稿在那一层就被过滤掉了——
所以不存在「某个页面忘了过滤」这种漏洞。

## 发布一篇草稿

把 `draft: true` 删掉，提交：

```bash
git commit -m "feat(blog): 发布《草稿是怎么被藏起来的》"
```

钩子会在这时注入当天的 `date`——**发布日期永远是真正发布的那一天**，
而不是开始动笔的那一天。
