## 你现在看不到这篇文章

如果你在 `npm run dev` 的本地预览里读到这些字，是正常的；如果线上站点也能读到，说明草稿过滤失效了——那是个 bug，请告诉我。

因为这篇 frontmatter 里写着：

```yaml
draft: true
```

## 草稿的规则

| 行为 | 开发环境（`npm run dev`） | 生产构建 |
| --- | --- | --- |
| 生成页面 | ✅ 可预览 | ❌ 完全没有产物 |
| 列表 / 归档 / 标签 / 分类 | ✅ 带「草稿」标识 | ❌ |
| RSS / OG | ✅ 可预览 | ❌ |
| sitemap / Pagefind | —（dev 不生成） | ❌ |
| 注入 `date` | 允许缺失 | 草稿不参与发布 |

所有列表都走同一个入口 `getPublishedPosts()`：开发环境保留草稿，生产构建在那一层统一过滤——
所以不存在「某个页面忘了过滤」这种漏洞。

## 发布一篇草稿

把 `draft: true` 删掉，提交：

```bash
git commit -m "feat(blog): 发布《草稿是怎么被藏起来的》"
```

钩子会在这时注入当天的 `date`——**发布日期永远是真正发布的那一天**，
而不是开始动笔的那一天。
