## 你能读到这篇文章，说明

1. 有人把密码告诉了你，或者
2. 你就是站点主人

因为这篇内容在**构建时就被加密了**，页面源码里从头到尾只有密文。没有密码的话，
搜索引擎、爬虫、以及任何拿到 HTML 的人都只能看到一堆 base64。

## 加密是怎么做的

```
构建期（本地/CI）：PRIVATE_PASSWORD → PBKDF2 派生密钥 → AES-256-GCM 加密正文 → 页面只存密文
访问时（浏览器）  ：用户输密码 → 本地 PBKDF2 派生 → 本地解密 → 渲染正文
```

- PBKDF2：SHA-256，**600,000 次迭代**，站点级固定盐
- AES-256-GCM：每条内容随机 `iv`，篡改会直接解密失败
- 密钥全程留在浏览器：**密码不上传、不落盘**

## 怎么用

在文章 frontmatter 里加一行：

```yaml
private: true
```

然后在 `.env` 里设置密码：

```
PRIVATE_PASSWORD=你的强密码
```

访问入口在页脚的「私密」，或者直接打开 `/private`。

## 几个细节

- 私密文章**不进**列表 / 归档 / 标签 / 分类 / RSS / sitemap / 搜索索引，页面带 `noindex`
- `/private` 入口页的清单本身也是加密的——**没解锁时连篇数都不会暴露**
- 解锁状态记在 localStorage，时长由 `PUBLIC_UNLOCK_TTL_HOURS` 控制（默认 1 小时）

## 一句提醒

加密只在**仓库私有**的前提下才有意义——明文 Markdown 就躺在你的私有仓库里。
